## 📥 How to Install on Your Android Device

1. **Download Either APK**:
   - Tap [**Download v2 Offline AI**](https://github.com/Parshuram9353/NutriSnap/raw/main/release/NutriSnap-v2.0.0-OfflineAI.apk) OR [**Download v1 ChatGPT**](https://github.com/Parshuram9353/NutriSnap/raw/main/release/NutriSnap-v1.0.0-ChatGPT.apk).
2. **Enable "Install Unknown Apps"**:
   - Open the downloaded file from your browser's download manager or phone's **Files** app.
   - If prompted *"For your security, your phone is not allowed to install unknown apps from this source"*, tap **Settings** and turn on **Allow from this source**.
3. **Install & Launch**:
   - Tap **Install**, then tap **Open** to start using NutriSnap!
